## 议题一：原型整体业务流程贯通情况（流程层面，不逐页演示）

几条主要业务流程在原型中已全部跑通：

1. **租赁主流程**：租入 → 入库 → 租赁出库 → 在租 → 退租入库 → 归还出库（含转移出库）；
2. **背靠背直发流程**：直发租入 → 虚拟仓自动流转 → 直发租赁出库 → 退租自动闭环归还供应商（不占实体仓）；
3. **买卖流程**：销售订单 → 销售出库 → 退货；采购订单 → 采购入库 → 退货；
4. **仓储作业**：库存查询（多视角）→ 盘点 → 调拨 → 其他出入库；
5. **财务协同**：应收 / 应付账单 → 收付款 → 核销与发票。

- 会上按流程层面说明整体贯通、**可进入下一步排期**；不逐页演示细节，领导有问询再现场打开对应页面。
