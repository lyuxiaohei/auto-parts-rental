# 项目文档编码（挂靠式）

> 事实源：各项目主文档附录「文档体系与编码规则」（首建于投资项目管理 P2-R01 第十节；两项目均已落地：项目 02 投资项目管理 `P2-R01-产品需求文档.md` 第十节 · 项目 01 AI知识库 `P1-R01-方案分析报告.md` 附录，2026-08-27 定稿）。本文件为操作细则副本，与附录冲突时以附录为准。

## 结构

```
阶段级：  Pn-R序号-中文标题                 （R 系列序号流水：R01=该阶段主文档，R02+=同阶段独立产出文档，如 P1-R02-术语表）
挂靠级：  Pn-挂靠文档码-{A|D|F}序号-中文标题  （A=附件 / D=设计文档 / F=图，可多层嵌套）
```

- Pn = 阶段序号（P1 方案分析 / P2 功能调研 / P3 原型 / P4 技术方案…；新项目按业务自定，语义在 R01 附录声明）
- 嵌套实例：`P2-R01`（PRD）→ `P2-R01-D01`（流程图集设计文档）→ `P2-R01-D01-F01`（十二阶段全图）
- F 图双格式：HTML 高清（可缩放）+ PNG（嵌入用）同名成对

## 目录布局（层级对应）

```
项目根/
├── P1-R01-方案分析报告.md        ← 阶段级（R 主文档 / D 独立产出物）置根目录
├── P1-R02-术语表.md
├── P2-R01-产品需求文档.md
├── P1-R01/                         ← 挂靠材料按挂靠文档码入文件夹，平铺不分层
│   ├── P1-R01-A01-竞品分析.md
│   └── P1-R01-F01-类型架构对比图.html/.png
├── P2-R01/
│   ├── P2-R01-D01-项目阶段流转与操作流程图.md/.html
│   └── P2-R01-D01-F01~F06-*.html/.png
└── 99-归档/
```

文件夹内平铺不再建子层：文件名自带全码（含完整挂靠链），文件夹只是物理归位。

## 规则要点

1. **一切支撑材料必须挂靠**：附件、设计文档、图不得游离在阶段级；独立成篇的产出物用阶段级 R 续号（如 `P1-R02-术语表`）
2. 序号在**各挂靠文档内**独立流水；目录层级与编码层级一一对应（阶段级置根目录，挂靠材料入 `挂靠文档码/` 文件夹平铺）
3. **空号不复用**：材料升格/废止后原序号留空并在主文档附录记「更名历史」（编号①②③…递增，条目保留当时编码原貌）
4. 标题用**中文全称**，不带日期、「文档」等冗余后缀；例外：归档快照等无编码文件可带日期
5. 跨文档引用一律写**全码**，禁用裸写缩写（D01/A02/F03 单独出现会跨阶段歧义）；仅两处豁免：附录清单行（行首已给全码，行内可缩略）与更名历史条目（保留当时编码原貌）
6. 同一材料被多文档引用时，以挂靠文档为**唯一维护处**
7. 已废止形态（勿再使用）：阶段级独立 A/F 编码（`Pn-A0N`/`Pn-F0N`）、游离 D 编码（`P2-D0N`）、阶段级 D 编码（`P1-D01`，D 仅为挂靠级设计文档类型）、项目字母前缀（TZGL-/ZSK-）

## 附录双表

每个项目主文档（R01）维护：**10.1 编码规则**（上述内容 + 目录层级规则）+ **10.2 文档清单**（编码 ↔ 路径 ↔ 说明，含 99-归档 与「未来」行）。文件增删改或移动必须同步 10.2 的路径列。

## 操作规程

### 新建产出物
1. 判类型：阶段主文档→`Pn-R01`；支撑某文档→挂靠该文档码+A/D/F；独立成篇→`Pn-D0N`
2. 全项目（含 99-归档）检索拟用编码防撞号
3. 同步登记主文档附录 10.2

### 重命名
批量改名 → 全局替换引用（md 与 html 同步，含图内标题；**跨文件夹移动时根目录↔子文件夹的相对链接要加/去文件夹前缀，同文件夹内同级引用不变**）→ 修附录 10.2（含路径列）+ 追加更名历史 → 旧名快照 zip 移入 99-归档 → 跑一致性检查（`../scripts/check_consistency.sh`）

### 归档
原始输入（录音/转写/会议材料副本）、历史快照 → `99-归档/`；正文引用路径同步改为 `./99-归档/…`
