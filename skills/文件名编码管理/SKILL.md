# 文件名编码管理

适用范围：`D:\工作台-吕道远` 全域（含各 `5-【ACTIVE】/【DORMANT】` 项目文件夹）。

核心原则：**编码即位置**——看文件名即知所属项目、阶段、挂靠文档与类型；**目录层级与编码层级一一对应**。**规则细节的事实源是工作台内的源文件（见文末表），本技能只做路由**；冲突时以源文件为准并回头修本技能。

## 工作台目录层级速览

| 层 | 规则 |
|---|---|
| 分类目录 | `N-名称`：1-会议材料 / 2-技能 / 3-弹药库 / 4-个人材料 |
| 项目目录 | `5-【状态】项目名`，状态 ∈ {ACTIVE, DORMANT（≥25 天无动作可降级）}；切换只改状态标签，内容编码不动 |
| 项目内归档 | `99-归档/` 只读：原始输入（录音/转写）、旧名快照 zip；不参与编码 |

根元数据：`DIRECTORY-INDEX.md`（纯清单）、`DIRECTORY-CATALOG.md`（理解版）、`overview.md`、`skills-lock.json`。跨项目引用写「项目 NN《编码-标题》」且用对方现行文件名；两项目同码以文件夹区分，单独外发必须注明所属项目。

## rename_meeting.py 速记

- **一文件夹 = 一会议**；自动完成：日期推断（文件名显式日期 > 周X→最近匹配 > mtime 标「未知日期」）→ 主题提炼（去周X/时刻/Video时间戳等噪音词，ai→AI，≤20 字，**人名等措辞人工斟酌后可 `--theme` 覆盖**）→ 载体判型（扩展名 + rar 用 bsdtar 探测内含视频 + docx 嗅探发言总结/纪要）→ 转写/纪要带来源前缀（`[音频转写]`/`[视频转写]`/`[音频纪要]`/`[视频纪要]`）→ 同类型多份加 `~N` → 对照表 CRLF 追加 → 文件夹占用自动重试
- **主题优先级：系列名 > 文件名**——新会议若属已有系列（如「汽车物流包装租赁第N次…」），用 `--theme` 续写系列名保持连贯，即使文件名措辞不同（2026-09-04 定）
- **文件基名日期 = 该载体实际会议日期**——同系列后续场次落在另一天时，新开当日文件夹，不沿用旧文件夹日期（2026-09-05 定）
- 自动跳过 `.qkdownloading`（下载中）与系统文件；无法判型的文件跳过并提示人工定名
- 从视频提取音频：`ffmpeg -i 视频 -vn -c:a copy …[音频].m4a`，属新生成非改名，不入对照表
