# 原型标注

给静态 HTML 原型挂**双轨**注释层：**业务轨（biz，默认）**＝锚点文字后内联「?」小圆标（素材图·常显无需开关），点击弹出小弹窗（标题＋说明＋× 关闭，点外/Esc 亦关）——**? 圆标及其内容＝正式功能需求，需开发到最终前端页面（面向最终用户）**；**开发轨（dev）**＝紫色方形数字角标（标注开启态显示），点击开右侧抽屉并定位条目——仅开发过程内部查看，正式版不出现。抽屉三通道开关：右下角「标注 N」按钮 / `Alt+N` / `?notes=1`（仅当页初始开·默认不展示·不跨页记忆）。**代号展开**：数据含 codes 映射时，FP/REQ 标签渲染为「编码 · 全称」并在条目附出处块，不出现裸代号。

**核心原则——原型与标注分离**：页面本体不带任何元注释（FP/REQ 编号、括号说明尾巴、★ 标记、pn-hint 类重复说明），全部由标注层承载。默认打开=干净业务原型（可演示），点开关=需求规格。

## 现行架构（0918 G52 抽屉制＋0919/0920 双轨）

- **页面只保留两样**：目标元素 `data-note="N"` 数字标记＋`</body>` 前两行共享件引用（notes-data.js 在前、notes-drawer.js 在后）。说明文案一律不进页面。
- **文案真值源**＝`P3-R01-A03-标注数据.json`（项目侧）→ **人工同步**到 `_data/notes-data.js`（运行时），两处必须同步改。改标注只动这两个文件＋必要时页面锚点，不碰共享件渲染逻辑。
- 共享件 `_data/notes-drawer.js` 按 `aud` 字段自动分轨渲染，页面零改动。

**双轨规则（0919 道远拍板：属于开发产品看的内容放注释；业务需看的做成 ? icon）**：

| 轨道 | 条目字段 | 页面呈现 | 触发 |
|---|---|---|---|
| **业务（biz，默认）** | 不写 `aud` 字段 | 锚点**文字右侧** ? 圆标（**素材图 `项目原型素材/问号-V2.png` 内嵌 base64 作 mask 蒙版·填充色默认灰 #8c8c8c（蓝底按钮 `.btn:not(.btn-default)` 内自动改白）·14px·间隔 10px**·插入最深层含文本子元素内——flex/space-between 容器不会甩到行尾·0920 道远六轮修正——正式组件排版语言，非角标悬浮） | **点击弹出小弹窗**（黑白卡：标题＋说明＋× 关闭·点外/Esc 亦关；不悬停）；不进抽屉定位 |
| — **biz 用途定性（0920 道远）** | — | **? 圆标及内容＝正式功能需求，需开发到前端页面（面向最终用户）**——note 文案必须面向用户，禁写 D 号/会议/人名/日期等过程信息（过程信息归 dev） | |
| **开发（dev）** | `"aud": "dev"` | 紫色**数字角标**（标注开启态显示） | 点击开右侧抽屉并定位条目；抽屉条目带「开发」紫徽标——**仅开发过程内部查看，正式版不出现** |

- **dev 判定标准**：拍板沿革/演示机制说明（D 号、G 号、会议日期）、数据对齐口径（演示链对账）、实现机制（同源同步/正式版行为）、设计预留待拍板字段——写给产品与开发看的内容。
- **biz 判定标准**：业务规则/字段业务含义/流程口径/库存与计费口径——客户与业务方需要看懂的内容（主体是业务规则即归 biz，过程信息拆去 dev 条目）。
- 抽屉仍列全部条目（biz 带「业务」蓝徽标、dev 带「开发」紫徽标），fab 计数=全量；本页无标注数据 fab 自动隐藏。
- 数据维护：A03 json 与 notes-data.js **两处同步**加 `"aud": "dev"`（biz 不写字段）；条目字段序 id →（aud）→ selector/title/note/fp/req。
- 已标 dev 存量（2026-09-20 方案 A 拆分后共 18 条）：首批 6 条（BOM维护#3 维护时点拍板、损益报表#2 演示链数据对齐、用户权限#3 同源同步机制、租赁单新建#1/#2 预留待拍板、审批详情#1 静态演示）＋方案 A 从 biz 拆出沿革 12 条（库位口径沿革/盘点行内生成/库存查询三条/物料档案合并/直发口径/退款登记/转移出库与结算沿革等）。

### ? 圆标素材图机制（0920 道远指定）

- **素材真值源**＝原型根 `项目原型素材/问号-V2.png`（200×200 透明底单色线条 PNG·0920 V2 换图入库·旧问号.png 已删）——换风格换此图；mask 方案下图片只承载形状，须单色透明底线条图。
- 运行时**不引用图片文件**：notes-drawer.js `.pn-q` 样式内嵌 base64 data URI。原因：页面分布根级/一级目录两层，相对路径必有一层 404；内嵌后共享件自包含，外发打包随 _data 单件走不漏素材。
- **换图流程**：新图（单色透明底线条图）→ base64 → 替换 `.pn-q` 规则 mask 两处串（background 图已退役）→ **解码 md5 与原图复核一致**（⚠️ 长串手贴易出转录误差：0920 实测偏移 5029 处 1 字符错、长度相同肉眼不可见，md5 必查）→ PW/截图目检（图标渲染/内联位置/点击弹窗/JS 0）。
- 形态：14px·**间隔 10px（margin-left）·插入锚点最深层含文本子元素内**（0920 道远「放文本右侧」——直接追加到锚点尾会被 flex/space-between 容器甩到行尾，如我的待办统计卡标签；替换类元素 SELECT/INPUT/TEXTAREA/IMG/SVG 跳过）·hover 仅透明度变化·无描边/底色/字体样式；JS 侧不写文字（纯背景图，无 `textContent='?'`）。

## 工作流程（现行·全程手动）

0. **清理原型本体重复说明**（若原型自带说明）：删标题括号尾巴（`主名（说明）`→`主名`）、★ 标记、含元引用（FP/REQ/待确认 #/决策 #）的 hint 行、CSS 注释来源说明；**业务口径/指标解释同样转标注**（0911 拍板）——判别：解释**为什么/怎么算/口径出处/范围边界**→删本体转标注；提示**怎么操作/字段状态**→保留。**保留**纯交互/状态提示与业务状态词（如订单「待确认」标签是状态不是元引用，勿误删）。
1. **确定标注数据来源**：从需求文档（FP 功能点表/REQ 清单）提取；没有编码体系时 `fp`/`req` 留空。逐条判定 biz/dev（判定标准见上）。
2. **写标注数据（手动·双处）**：A03 json 与 notes-data.js **两处同步**逐条手动 Edit。selector＝页面 HTML 原文子串（非 CSS 选择器），仅作人工定位锚点参考——现行匹配只按 `data-note` 数字，不做子串替换；消歧带 onclick/唯一属性；指向 input/img 等替换元素时挂父级。
3. **页面锚点（逐页手动加）**：给页面元素挂标注＝在该元素开标签手动加 `data-note="N"`＋`</body>` 前两行共享件引用（若页尚无）。**一页一页、一条一条加，不许脚本批量注入**。
4. **验证（只读脚本可用）**：`node --check`＋json load；PW 默认态（? 圆标常显·点击弹窗开合·内联落锚点框内）＋开启态（dev 数字角标/抽屉定位）；biz 文案过过程词正则（D 号/会议/人名/日期清零）；A03↔notes-data 逐条 diff 零差异。
5. **登记**：拍板登记落账；本技能三副本（仓库 `skills/`｜`C:\Users\Administrator\.claude\skills\`｜`C:\Users\Administrator\.zcode\skills\`）同步一致（md5 校验）。

## 施工纪律（0920 道远）

- **不允许脚本跑——「很容易出错」**：加标注、挂 ? 圆标锚点、改文案、改页面/数据，一律**逐条手动 Edit、一个个去加**（A03＋notes-data 双处同步）；任何批量注入/替换/刷改脚本都不允许，旧 `scripts/annotate.py` **已退役勿再跑**。
- 例外＝**验证**：只读校验（node --check / json load / 审计脚本 / PW 渲染实测 / 截图）可用脚本，不属刷改。

## 边界与注意

- dev 数字角标形态：方形紫色小号（#722ed1、16px、3px 圆角、半透明 75% hover 实化、白描边、**内嵌元素右上角 top:1px/right:1px**——锚点横跨容器宽时即容器右上角（如统计卡标签≈卡片右上角）；外挂负偏移会被 .table-wrap 等 overflow 容器裁掉上半）——**方形是刻意决策：圆形+红橙色易被误认为消息徽标**；紫色系（角标/抽屉/标签）与业务层蓝 #1677ff 保持语义分层。
- 双轨互斥渲染：biz 条目在标注开启态不显数字角标（`::after` 被 display:none）、dev 条目不显 ? 圆标；? 弹窗与抽屉互不干扰（? 点击 stopPropagation 不开抽屉；Esc 兼关两者）。
- 快捷键 `Alt+N`（勿用 Ctrl+Shift+N——浏览器隐身窗口占用）；`?notes=1` 仅当页初始开、不锁死开关、不跨页记忆（0918 拍板默认不展示）。
- 单文件原型（file:// 直开）与托管原型（http）均可；不依赖网络（图标 base64 内嵌）。
- 共享件自包含（样式＋DOM 全在 notes-drawer.js），页面零依赖；面板灰阶/字号对齐 Ant Design 13px 体系。

## 已退役流程（勿执行）——annotate.py 三块注入制（G52 前）

旧制＝`python scripts/annotate.py --pages … --data annotations.json [--only] [--remove]` 往每页注入 style/div/script 三块＋便签就地弹出可多开、localStorage 记忆开关、幂等重跑一键移除。**0918 G52 起整体被抽屉制替代**（页面剥旧块换两行引用·文案集中 notes-data），上述特性不再使用；现行纪律＝手动逐条加（见施工纪律）。旧流程沉淀的 selector 经验（未命中/多处匹配/替换元素挂父级、优先带 class 开标签片段、grep 验证全页唯一）仍适用于手写数据与人工定位。
