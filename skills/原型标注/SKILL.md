# 原型标注

给静态 HTML 原型注入注释层：**右下角常驻淡紫「标注 N」入口按钮**（白底细描边、60% 透明不扰演示，点击开关，开启变「收起」）；开启后小号方形角标（紫色半透明，hover 实化）钉在目标元素上，点角标就地弹出说明便签（编号/标题/说明/FP·REQ 标签，可多张同开）。`?notes=1` / `Alt+N` / 右下角按钮三通道开关。**点角标区域（元素右上 24×22px）在 capture 阶段拦截，不触发元素自身的 onclick**；关闭态点击零动作；便签 z-index 低于业务弹窗遮罩。**代号展开**：标注数据含 `_meta.codes` 映射时，FP/REQ 标签渲染为「编码 · 全称」，便签底部自动附出处块（全称+要点说明），不出现无法理解的裸代号。

**核心原则——原型与标注分离**：页面本体不带任何元注释（FP/REQ 编号、括号说明尾巴、★ 标记、pn-hint 类重复说明），全部由标注层承载。默认打开=干净业务原型（可演示），点开关=需求规格。

## 工作流程

0. **清理原型本体重复说明**（若原型自带说明）：删标题括号尾巴（`主名（说明）`→`主名`）、★ 标记、含元引用（FP/REQ/待确认 #/决策 #）的 hint 行、以及 CSS 注释里的来源/参考说明（如 `/* xxx（参考某项目） */`→`/* xxx */`）；**业务口径/指标解释同样转标注**（2026-09-11 道远拍板）——统计卡指标下解释行（st-foot/mini-note，如"退租申请待审核 3 单""安吉智行 → 终端用户 3 批"）、指标名括号注释（"客户转租出（客户的客户）"）、口径说明行（"在途＝应入库未入库（…）"）、含会议/拍板/第一期/仅支持/取小/按周期等口径词的灰字说明行（pn-hint/`font-size:12.*#8c8c8c` div）——判别标准：解释**为什么/怎么算/口径出处/范围边界**→删本体转标注；提示**怎么操作/字段状态**→保留。**保留**纯交互/状态提示（如「自动生成不可编辑」「已盘 N/M 项」）和业务状态词（如订单「待确认」标签——是状态不是元引用，勿误删）。
1. **确定标注数据来源**：从项目需求文档（如 FP 功能点表/REQ 清单）提取。没有编码体系时 `fp`/`req` 可留空。
2. **写标注数据**：格式见 [references/annotation-format.md](references/annotation-format.md)。⚠️ **必须在干净（未注入）页面上生成/校验 selector**——已注入页面元素带 `data-note` 属性，重找 selector 会把污染版写进数据（先 `--remove` 或在剥离注入块的副本上匹配）。
3. **注入**：
   ```bash
   python scripts/annotate.py --pages <原型根目录> --data annotations.json [--only 某页.html] [--remove]
   ```
   输出每页命中数；`未命中 / 多处匹配 / 替换元素` 三类告警必须逐条处理。幂等可重跑。⚠️ 已知缺陷（2026-09-11）：`--remove` 与 `--only` 组合时 `--only` 对移除不生效（会全站清除注入块）——处置：接受全站清除后**立即全站重注入**即可恢复；单页只想重注一页时直接重跑注入（幂等）即可，不必先 remove。
4. **验证**：Playwright 开一页默认态（无痕迹+右下角入口在）+ 开启态（角标/便签/点击联动）。
5. **登记**：标注数据文件登记项目主文档附录为唯一维护处；页面或标注改动后：改数据 → 重跑注入即同步（勿手改页面内注入块）。

## 边界与注意

- 只注入 `</body>` 前三个块（style/div/script）与目标元素的 `data-note` 属性，不改业务 DOM 与既有样式
- **selector 三类告警**：未命中、多处匹配（默认挂首个，须消歧）、指向 input/img 等替换元素（::after 不渲染，改挂父级）——注入输出的告警必须逐条处理
- 消歧写法：在开标签片段里带上 onclick 或唯一属性，如 `<button class="btn btn-primary" onclick="openModal` 优于 `<button class="btn btn-primary"`
- 快捷键为 `Alt+N`（勿用 Ctrl+Shift+N——浏览器隐身窗口占用）；localStorage 记忆开关，同源（含 file://）全站共享
- 单文件原型（file:// 直开）与托管原型（http）均可；不依赖网络
- 角标为**方形紫色小号**（#722ed1、16px、3px 圆角、半透明 75%  hover 实化、白描边、**内嵌元素右上角 top:1px/right:1px**——外挂负偏移会被 .table-wrap 等 overflow 容器裁掉上半，勿改回外挂）——**方形是刻意决策：圆形+红橙色易被误认为消息徽标**，勿改回圆形；低干扰形态，紫色系（角标/便签顶边/编号/FP·REQ 标签）与业务层蓝色 #1677ff 保持语义分层；便签 300px 宽；面板灰阶/字号对齐 Ant Design 13px 体系（#262626/#595959/#8c8c8c）；其他皮肤可在 STYLE 常量改色值
