# 标注数据格式与编写指南

## annotations.json 格式

```json
{
  "_meta": {
    "project": "汽车物流包装租赁",
    "source": "P1-R01-需求梳理与功能框架.md（FP/REQ 编码）",
    "date": "2026-09-01"
  },
  "仓储作业/小组装列表.html": [
    {
      "id": 1,
      "selector": "<button class=\"btn btn-primary\"",
      "title": "新增组装单 → 弹窗录单",
      "note": "点击弹出「小组装录单」modal：A+B→C，记录运营方/时间/数量。\n组装后子件库存转母件，库存双视角实时更新。",
      "fp": "FP3-02",
      "req": "REQ-06"
    }
  ]
}
```

字段说明：

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✓ | 页内序号 1..n，即角标数字与面板排序 |
| `selector` | ✓ | **原文子串**（非 CSS 选择器）：取页面 HTML 中该元素开标签的一段唯一原文，如 `<button class="btn btn-primary"`、`<th>循环状态</th>`。注入器用字符串替换挂 `data-note` |
| `title` | ✓ | 面板条目标题（≤20 字） |
| `note` |  | 说明正文，`\n` 换行。写交互逻辑/业务规则/边界 |
| `fp` / `req` |  | 回链需求文档的功能点/需求编码，显示为紫色标签；`_meta` 含 `codes` 映射时自动展开为「编码 · 全称」并在便签底部附出处块（全称+要点说明） |

## `_meta.codes` 代号映射（可选，推荐）

```json
"_meta": {
  "codes": {
    "FP3-02": {"name": "小组装单", "desc": "A+B→C，记录运营方/时间/数量；组装后子件库存转母件"},
    "REQ-06": {"name": "小组装管理节点", "desc": "记录 A+B→C 的组装时间与数量；库存双视角（零件/组合）"}
  },
  "codesSource": "P1-R01 三/四章 FP·REQ 表（唯一维护处）"
}
```

- 作用：便签里的 `fp`/`req` 不再裸显示代号——标签变「FP3-02 · 小组装单」，底部出处块给完整说明，读者无需翻需求文档
- 维护：从需求文档的 FP/REQ 表解析生成（脚本或手工均可），需求文档改了就重生成映射再重跑注入；映射里缺的编码自动降级为裸代号标签

## 从需求文档提取标注的映射法

1. 需求基线（P1-R01 类文档）里有 FP 功能点表：每模块「编码 | 功能点 | 要点说明 | 需求」。
2. 对原型每个页面，找出承载的 FP，逐个写条目：
   - 列表页：按钮（新增/导出/批量操作）、关键状态列（如「循环状态」）、筛选区新概念
   - 弹窗：触发按钮处标一条，note 里写弹窗内容摘要
   - 表单/录单弹窗：每个业务规则一个条目（如"组装后子件转母件"）
3. selector 稳定性原则：**优先带 class 的开标签片段**；避免纯中文文本（重名率高）；选长度适中且全页唯一的片段——写完后可 grep 验证唯一。
4. 一个 selector 只挂一个角标；同一元素多条说明合并进一个条目的 note。

## 锚点类型实战速查（批量生成 selector 用）

| 锚类型 | 正则（Python） | 注意 |
|---|---|---|
| 卡片标题 | `<(h3\|div) class="card-title"[^>]*>主名[^<]*</\1>` | **h3 与 div 两种形态并存**（详情页/双表页常用 div 带内联 style），匹配时两种都要兜 |
| 表头 | `<th>列名</th>` | 最稳的锚，列名全站基本唯一 |
| 按钮 | `<button[^>]*>按钮文字</button>` | 注意页面同名按钮（如多个「提交验收」）会多处匹配，带 onclick 消歧 |

## 陷阱：selector 污染

已注入页面元素带 `data-note="N"` 属性。**在任何已注入页面上重找/校验 selector，会把污染版（含 data-note）写进标注数据**，下次注入即失配。正确顺序永远是：

```
清理本体说明（若需）→ 在干净页面生成/校验 selector → 注入
   ↑ 页面已注入时先 --remove，或匹配时截断到 <div id="proto-pins"> 之前
```

若已污染：对 json 里所有 selector 跑一遍 `re.sub(r'\s*data-note="\d+"', '', sel)` 清洗。

## 交互行为（注入后）

- 默认隐藏零介入；开启三通道：**右下角紫色「标注 N」常驻按钮（可发现入口，推荐）**、URL 加 `?notes=1`、快捷键 `Alt+N`；开启后按钮变「收起标注」
- localStorage 记忆开关状态（同源全站共享；file:// 页面同源）
- **点角标（元素右上 24×22px 区域）就地弹出说明便签**，capture 阶段拦截不触发元素自身 onclick；再点角标或点便签 × 关闭；多张便签可同时钉开
- 便签 300px 宽，智能定位（右侧优先，溢出自动翻左/上）；z-index 890，低于业务弹窗遮罩
- 关闭态下点击被标注元素**零动作**（防演示误触）

## 幂等与移除

- 重复注入自动清理旧块（style#proto-notes-style / div#proto-notes-panel / script#proto-notes-js 及 data-note、proto-note-target）后重注，可反复运行更新标注
- `--remove` 一键还原页面到无标注状态
