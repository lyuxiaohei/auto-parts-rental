> **归档时间**：2026-09-03

> **说明**：本档为 Agent 原始调研报告原文归档，P1-R07 为综合提炼版

## 一、核心发现

- 单据链路最完整的是 CHEP（myCHEP）和傲蓝
- 审核+反审核是标配；多级审核独立成菜单（运腾）
- 计费收敛到"箱天/设备天数"，结算收敛到"周期快照制"
- "退租申请"与"验收销账"强制分离是行业铁律

## 二、myCHEP 完整链路

```
开户签约（授信审核）→ 租赁订单（4种入口）→ 发货单 delivery docket
→ 在租台账（按账户记 equipment-days）
→ 过户单 CMD（发出方申报→接收方确认）
→ 退租申请（collection）→ 退租验收销账（回仓签收才停计费）★两阶段分离
→ 纠错冲销单（60天窗口）→ 周期发票 → 收款
```
特色：账户负库存自动 Suspended 挂起；丢失设备赔付前持续计日租

## 三、傲蓝（国产最完整单据驱动）

### 周材线
```
租出合约（计费规则载体）→ 租出单（起算租金）→ 报停单/调价单
→ 回收单（止算租金，支持部分回收）→ 丢损赔偿单
→ 租出结算单（按对账截止日自动生成）→ 租赁发票 → 租出收款单
```

### 设备线（起租/停租是独立计费开关）
```
合约 → 出库单 → 安装单 → 起租单（开始计费）→ 报停/停租/调价 → 拆卸单 → 回库单 → 丢损赔偿 → 结算 → 收款
```

### 傲蓝菜单树（行业通用骨架）
```
首页仪表盘（仪表首页、物资分布地图）
设备租出管理：租出合约/出库单/预埋单/安装单/起租单/停租单/报停单/拆卸单/回库单/丢损赔偿单/调价单/派工单/运输作业
周材租出管理：租出合约/租出单/回收单/丢损赔偿单/报停单/调价单
维修保养管理：保养单/维修单/整改单/保养提醒
租入管理：租入合约/租入单/归还单/丢损赔偿单/报停单
财务管理：租出结算单/租赁发票/收款/坏账/其他费用/租入付款
进销存管理：物资分布/采购入库/销售/调仓/其他出入库
系统管理：材料/设备/仓库/客户/工程项目/丢损赔偿价/审核设置
报表：30+张
```

## 四、路凯/睿池/携赁

- 路凯：电子签约→在线下单→配送+电子签收→在租→托管转移单→通还→验收止租→月结账单→在线支付（70%客户开通）
- 睿池：发货事件触发起租（收箱≠起租）→验收止租；动态按次/静态按天
- 携赁：RFID+Union Plus Cloud，系统实现基本无公开资料
- 普拉托：普托云仓自动起租/退租/结算；普托云签双重确权

## 五、汽车租赁

### 易租 eZu（单据命名最完整）
```
预定单 → 出车单（出车验车=基线登记）→ 在租 → 还车验车单（与基线对比出差异）
→ 结算单（自动归集：租金+超里程+超时+保险+增值服务）
→ 收款单/发票 ∥ 违章单（独立单据流，不阻塞主结算）
```

### 一嗨赔偿拆项（教科书）
维修费（预付多退少补）+ 停运费 + 贬值费 + 物品损失，全部作为结算单独立费用行；押金双段释放

## 六、通用进销存
- 管家婆：借出单→借出还回单→借转销售（无租金押金）
- 畅捷通T+：建出租仓+客户建为项目→出租填调拨单→报表分组出在租台账（钱物两条线手工关联）
- 用友NC：唯一有真租赁模块的（租出/归还/租金计算/到期预警）

## 八、值得直接搬的设计元素

1. 合约是计费规则载体（单价/计费方式/赔偿价/押金都挂合约）
2. 起租/止租由事件触发（发货审核完成起租、验收完成止租）
3. 报停单/调价单作为在租期变更独立单据
4. 丢损赔偿单参照合约自动带出在租明细
5. 退租两阶段（申请→验收销账）+ 验收拍照归档
6. 结算单=时间区间快照+确认，支持预对账
7. 主结算与争议/赔偿解耦
8. 入库类型细分"归还入库/修复入库"
9. 客户端按动作组织
10. 租售混合=租赁订单与销售订单并列、各自下推出入库
