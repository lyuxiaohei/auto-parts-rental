## 一、金蝶云星空

### 销售主流程（下推式）
```
销售报价单 → 销售订单 ──下推──→ 发货通知单 ──下推──→ 销售出库单 ──下推──→ 销售发票
                 │                    │                  │
                 │                    │                  └→ 应收单→应收单（财务应收）
                 └──收款计划←──── 收款单（按订单收款计划核销）
```
- 功能路径：【供应链】→【销售管理】→【订单处理】→【销售订单】
- 下游数量反写上游；信用校验挂在销售出库单保存时
- 监控报表：销售订单执行明细表（发货/出库/应收/开票/收款五段）

### 组装拆卸单
- 功能路径：【供应链】→【库存管理】→【组装拆卸】
- 事务类型=组装（子件↓成品↑）/ 拆卸（反向）；参照 BOM 单号
- 成品明细/子件明细双页签；成本=子件之和+组装费用
- 销售订单可直接关联生成组装单

### 套件 Kit 模式（A+B→C 对应）
1. 父项设"套件"属性→不允许库存、不允许生产
2. 销售订单选套件父项→自动按 BOM 展开子项行
3. **销售出库单上父项不更新库存，只有子件扣库存**
4. 应收单只携带父项（按套确认收入）

### 菜单结构
- 采购管理：申请处理/订单处理/收料处理/退料处理
- 销售管理：订单处理/订单变更/发货通知/销售出库/退货处理/价格与折扣/信用管理
- 库存管理：初始化/出入库/调拨/组装拆卸/盘点/库存查询
- 命名规律：【模块】→【业务域】→【单据/动作】

## 二、用友 U8+ 资产租赁管理（最完整官方租赁模块）

### 菜单树
```
资产管理
└─ 资产租赁管理
   ├─ 设备卡片（附卡：租赁页签/租金页签）
   ├─ 租赁申请
   ├─ 外部租赁：对外租出/对外租出归还/外部租入/外部租入归还
   ├─ 内部租赁：对内租出/归还（协同单据）
   ├─ 租金计算：应收租金计算/应付租金计算/租金收款/租金付款
   └─ 台账报表：租出及归还台账/租赁应收台账/租赁应付台账
```

### 完整流程闭环
```
租赁申请 → 对外租出单（审核→回写设备卡片→推式生成出库单）
  → 按期应收租金计算（月/季/半年/年+起缴日期）
  → 租金收款（核销金额回写"应收租金计算单.实收租金"）
  → 对外租出归还（推式生成入库单，归还时做丢赔）
  → 关闭对外租出单（合同到期+设备全归还+费用结清）
```

### 关键字段（对外租出单）
- 表头：承租公司/租赁合同号/起租日期/止租日期/租金缴纳方式/起缴日期/租金总额/押金/保证金/订金
- 表体（双页签）：租赁内容（存货+规格+数量）/租赁明细（具体设备编码）/租金标准

### 用友 NC Cloud 周转材
- 租出合同→租出单（发料）→赔偿单/丢赔→归还单→租赁结算单（含赔偿）→收付款
- BIP 资产云："资产租入到付款、租出到收款"全过程运营

## 三、金蝶 T+ / 畅捷通
- T+ 组装拆卸单：物料清单（BOM）→组装拆卸单→自动生成其他入库单（父项增加）+其他出库单（子件减少）→需二次审核
- T+ 无经营租赁模块

## 四、管家婆
- 借出单→借出还回单→逾期走借转销售单
- 无租金计费、无押金、无租期管控

## 五、SaaS 进销存（旺店通/秦丝/易订货）
- 均无经营租赁模块

## 六、建筑周转材租赁（智建互联等）
- 全链路：采购→租赁合同→发料→回收→维修→运输→丢赔→报停→租费结算→租费确认→收付款
- 单据化：发料单/回收单/维修单/运输单/丢赔单/报停单/租费结算单/租费确认单/收付款单
- 进出场费（安装/拆卸/报检/运费）与周期租金分开计价

## 七、循环包装
- 睿池 ULP：金属周转箱 65 万+，年周转 800 万次
- 优乐赛：动态租赁（随货流转按次）vs 静态租赁（场地存放按天）
- 携赁：RFID 芯片，扫码枪/物流门自动读取
- 台湾 TMS ERP：借出按分/时/日/月/年计租→自动产生租金收据+保证金收据→归还自动退保证金

## 八、对比排名

| 排名 | 产品 | 闭环覆盖 | 短板 |
|---|---|---|---|
| 1 | 用友 U8+ 资产租赁管理 | 全单据化+台账齐 | 管的是资产卡片，不是数量池；无组合拆散 |
| 2 | 建筑周转材 SaaS | 合同→发料→回收→维修→丢赔→报停→结算→确认→收付款 | 需与财务ERP外挂 |
| 3 | NC Cloud 周转材 | 合同/租出/归还/结算/赔偿齐全 | 文档公开度低 |
| 4 | 金蝶星空 | 无租赁模块；但供应链下推+套件BOM最成熟 | 租赁需二开 |
| 5 | T+/管家婆 | 仅组装拆卸/借欠 | 无计费 |
