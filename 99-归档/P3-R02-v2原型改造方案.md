## 一、项目背景（简要，仅供理解）

我们正在为一家汽车物流公司开发一套包装租赁管理系统，替换他们现有的两套外部系统。客户的业务分为两条独立主线：

1. **零部件买卖**：纯贸易，买什么卖什么（买A卖A），不涉及组装。单据流程：采购订单 → 采购入库 → 销售订单 → 销售出库 → 结算
2. **循环包装租赁**：购买围板箱、托盘等可循环物流器具，组装成组合租赁单元（例如：组件A + 组件B = 组合单元C），出租给客户使用，客户用完后退租，按散件（A、B单独）入库，再循环出租

两条主线共用：项目管理（上下游关系绑定）、基础资料（客商/器具/零部件/BOM/库位）、财务模块（应收/应付/损益）。

- 每个页面是完全独立的单个 HTML 文件（内嵌 CSS 和 JavaScript），无外部依赖，用浏览器直接打开（file:// 协议）
- 侧边栏菜单是逐页复制的 HTML 代码（没有共享脚本），修改菜单必须批量修改所有页面
- 侧边栏底部左下角有系统切换器（点击弹出浮层切换到客户端系统）
- 页面顶部有页签条（Tab 导航）
- 页面使用 Ant Design 风格设计规范（主色 #1677ff，字号 13px 体系）
- 部分页面有可开关的标注层（右下角紫色「标注 N」按钮，点击显示数字角标和说明便签）

### 3.2 菜单术语更名对照表（12 项，必须严格执行）

| 序号 | 当前菜单名（v1） | **v2 定版菜单名** | 更名原因 |
|---|---|---|---|
| 1 | 企业管理 | **客商管理** | "企业管理"在 SaaS 软件中专指租户/组织后台管理，与客户供应商档案的语义冲突；行业标准叫法是"客商管理"（用友 NC）或"往来单位"（管家婆/用友 T+） |
| 2 | 子母件BOM | **BOM** | "子母件"是快递行业术语（母单号挂子包裹），与物料清单语义无关；行业标准直接叫 BOM 或"物料清单"；文档和页面内的字段应改为"父项/子项"（原来叫"母件/子件"） |
| 3 | 小组装 | **组装** | "小"字无行业先例，读起来像临时操作；金蝶/用友标准单据名就叫"组装"或"组装拆卸单" |
| 4 | 包材档案 | **器具档案** | "包材"在制造业默认指一次性包装耗材（纸箱/泡沫），与可循环租赁资产的语义相反；汽车行业叫"物流器具"或"器具"（联友科技"器具管理公司"） |
| 5 | 拆散作业 | **拆卸管理** | 行业标准动词是"拆卸"（金蝶/用友"组装拆卸单"）；与"组装"对仗 |
| 6 | 在租资产跟踪 | **在租台账** | 行业主流叫"台账"（傲蓝"租出台账"、CHEP"on-hire balance 在租余额"）；"跟踪"偏物联网语境 |
| 7 | 订单协同 | **订单管理** | "协同"在行业中总是挂在"供应商协同平台"下作子模块；独立作一级菜单的行业惯例叫"订单管理" |
| 8 | 基础数据 | **基础资料** | 金蝶云星空标准叫法是"基础资料"；用友叫"基础档案" |
| 9 | 往来单位（页面文件名） | **客商管理**（页面文件名也改为 客商管理.html） | 同序号 1 |
| 10 | 回款登记（菜单已改，页面标题未改） | **收款登记** | 会计准则标准词"收款"；"回款"是口语 |
| 11 | 银行水单核销（菜单已改，页面标题未改） | **收款核销** | "水单"是银行回单的俗称 |
| 12 | 盈亏报表（菜单已改，页面标题未改） | **项目损益** | 财务报表标准术语："损益"（利润表） |

### 3.3 菜单结构重组（5 处）

| 序号 | 重组操作 | 详细说明 |
|---|---|---|
| 1 | **新增「采购管理」一级菜单** | 包含子菜单：采购订单（新页面）。这是第 2 次沟通会议确认的新增模块 |
| 2 | **新增「销售管理」一级菜单** | 包含子菜单：销售订单（新页面）。行业惯例销售订单不能挂在采购管理下，必须独立模块 |
| 3 | **「租赁管理」更名为「包装管理」** | 不是简单改名，子菜单也要调整（见下文完整菜单树） |
| 4 | **「财务协同」拆分为「财务应收」+「财务应付」+「项目损益」三个一级菜单** | 财务应收 = 我方向客户开票、客户给我们钱；财务应付 = 供应商向我方开票、我们付供应商钱（新增模块）；项目损益 = 收入减成本（两侧都要算） |
| 5 | **「客户端」取消独立系统，并入「订单管理」** | 第 2 次会议确认客户实际是发采购订单（PO）给项目经理、由项目经理代为下单，不需要独立客户端系统；下单功能合并到订单管理模块 |

### 3.4 删除项（3 项）

| 序号 | 删除对象 | 原因 |
|---|---|---|
| 1 | 包装管理 → 组合方案（菜单项） | 与基础资料下的 BOM 功能完全重复：BOM 定义配方关系（A+B=C），组装单执行配方，退租入库单反向引用 BOM 拆回散件。"组合方案"页面不需要存在 |
| 2 | 客户端/下单.html、客户端/我的订单.html | 并入订单管理模块；客户由项目经理代下单 |
| 3 | 客户端系统切换器（所有页面侧边栏底部的 ⇄ 切换按钮） | 客户端取消后不再需要系统切换 |

## 五、新增页面清单（14 页）

每个新页面的规格说明。所有新页面必须遵循 Ant Design 风格设计规范（与现有页面保持一致）。

### 5.1 采购管理/采购订单列表.html ★新增

**功能**：向供应商下采购订单（买零件或买包装器具），支持先销后采（客户先下销售订单，再触发采购）和先采后销（先囤货再卖）两种模式。

**页面结构**：筛选区 + 状态页签 + 数据表格 + 分页器 + 录单弹窗

**筛选字段**：采购订单号 / 供应商（下拉选择客商管理中的供应商类型企业）/ 物料类型（零部件/器具）/ 订单状态 / 下单日期范围

**状态页签**：全部 / 待审核 / 已审核 / 已完成 / 已关闭

**表格列**：采购订单号 / 供应商名称 / 物料类型 / 采购明细摘要 / 数量 / 金额（元）/ 币种 / 预计到货日期 / 关联销售订单号（如果先销后采）/ 订单状态（待审核/已审核/已完成/已关闭）/ 操作（编辑/审核/关闭）

**按钮**：新建采购订单（弹出录单弹窗）/ 批量导出

**录单弹窗关键字段**：
- 供应商（必填，下拉选择客商管理中的供应商类型企业）
- 物料类型（必填，下拉选择：零部件 / 器具）
- 关联销售订单号（选填，如果先销后采则自动带出）
- 明细表（物料编码/名称/规格/单位/数量/单价/金额，支持添加多行）
- 预计到货日期
- 备注

### 5.4 仓储作业/退租入库列表.html ★新增

**功能**：从退租验收流程中拆出的独立入库单据。退租申请审核通过后，自动生成退租入库单，按 BOM 配方将组合单元拆回散件入库。

### 侧边栏重生成规则

由于菜单是逐页复制的 HTML，需要批量修改所有页面。具体操作：

1. 从任意现有页面提取侧边栏的 HTML 图标代码（每个一级菜单有对应的 SVG 图标）
2. 按第四节的完整菜单树，重新生成侧边栏 HTML 代码
3. 对每个页面，设置正确的 `selected` 高亮（当前页面对应的菜单项高亮）和 `open` 展开（当前页面对应的分组展开）
4. 删除侧边栏底部的系统切换器（因为客户端已取消）
5. 所有页面的菜单结构必须完全一致（一致性检查：全站菜单文本序列唯一值 = 1）

## 十、设计规范（新页面必须遵循）

1. **设计系统**：Ant Design 风格，主色 `#1677ff`，字号 13px 体系，表格头背景 `#fafafa`
2. **页面结构**：顶栏（44px，Logo"包装租赁管理后台"）→ 侧边栏（208px）→ 页签条 → 内容区
3. **侧边栏底部**：显示"包装租赁管理后台"当前系统标识（不需要系统切换器，因为客户端已取消）
4. **表格**：筛选区（查询条件+查询/重置按钮）→ 状态页签 → 数据表格 → 分页器（条数/页码/每页条数/跳转）
5. **单文件**：每个页面是独立的单个 HTML 文件，内嵌 CSS 和 JavaScript，无外部依赖
6. **标注层**：如果需要添加标注，使用「原型标注」技能（`~/.claude/skills/原型标注/`），但标注数据需要单独维护
