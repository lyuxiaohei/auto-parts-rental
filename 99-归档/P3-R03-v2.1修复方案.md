## B. 项目管理页面问题（7 项）

### B1. 下拉框交互（全站）

**问题**：全站 `.ctl.sel` 类下拉框无选项数据，无法选择。

**操作**：检查每个列表页筛选区的下拉框，填入示例选项。常见下拉框及选项：

| 页面 | 下拉框 | 选项示例 |
|---|---|---|
| 销售订单 | 状态 | 全部 / 待审核 / 已审核 / 待发货 / 已完成 |
| 采购订单 | 状态 | 全部 / 待审核 / 已审核 / 已完成 |
| 采购订单 | 物料类型 | 全部 / 零部件 / 器具 |
| 租赁单 | 状态 | 全部 / 待审核 / 已审核 / 在租 / 已退租 |
| 退租申请 | 状态 | 全部 / 待审核 / 已审核 / 待入库 / 已入库 |
| 应收账单 | 状态 | 全部 / 待确认 / 已确认 / 已开票 / 已核销 |
| 应付账单 | 状态 | 全部 / 待确认 / 已确认 / 已付款 |
| 各出入库 | 状态 | 全部 / 待审核 / 已审核 / 已完成 |

**实现方式**：在每个 `.ctl.sel` 元素内部添加 `<select>` 元素（或 `<option>` 列表），使下拉可交互。如果已有 select 结构，填入 option 数据。

### B2. 项目编码规则简化

**文件**：`项目管理/项目档案.html`

**操作**：
1. 删除"编码规则"按钮和对应的 ruleModal 弹窗
2. 在"新建项目"弹窗中，编码字段改为只读，值自动填充格式：`PRJ-YYMMDD-XX`（如 PRJ-260903-01）
3. 在编码字段旁边加提示文字："自动生成：前缀+日期+序号"

### B3. 上下游绑定供应商改下拉多选

**文件**：`项目管理/项目档案.html`（上下游绑定弹窗）

**操作**：
1. 找到 bindModal 弹窗中的供应商/运营方/客户选择区域
2. 将文本标签（当前会换行的 span）改为 checkbox 列表
3. 每个选项一行，前面有复选框，后面是名称
4. 示例数据：一汽解放汽车有限公司 / 佛吉亚 / 博世 / 宁波华塑 / 招商路凯

### B4. 编辑弹窗改为新建同款 + 编码只读

**文件**：`项目管理/项目档案.html`

**操作**：
1. 行内"编辑"按钮打开的弹窗应与"新建项目"弹窗结构一致
2. 额外显示"项目编码"字段（只读灰色背景，不可编辑）
3. 其他字段与新建弹窗相同，但预填充当前行数据

### B5. 批量按钮需勾选后点亮

**涉及页面**：所有有"批量"按钮的列表页

**操作**：
1. 批量按钮（如"批量审核""批量导出""批量下发"）默认 `disabled` 状态（灰色，cursor: not-allowed）
2. 表格第一列的复选框勾选后，批量按钮变为可用状态（正常颜色）
3. 取消所有勾选后，批量按钮回到禁用状态
4. 实现方式：在 JS 中监听 checkbox 的 change 事件，动态切换按钮的 disabled 属性

### B6. 批量按钮布局统一

**涉及页面**：所有列表页

**操作**：
1. 批量按钮（批量审核/批量导出等）移到分页器同一行
2. 布局：批量按钮在左侧，分页器在右侧
3. 实现方式：在分页器 div 前面插入批量按钮容器，分页器用 `margin-left: auto` 右对齐
4. 移除原页头按钮区的批量按钮

### B7. 商务负责人改为项目负责人

**涉及文件**：
- `项目管理/项目档案.html`：表格列头"商务负责人"→"项目负责人"；新建弹窗字段标签"商务负责人"→"项目负责人"
