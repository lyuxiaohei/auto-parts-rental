## 五、结论与发现

1. **孤儿项：0**——全部弹窗与表单均有可达入口。
2. **录单交互全站统一为「按钮 + 弹窗」**：6 个独立表单页已删除并转为列表页 `modal-lg` 弹窗，无残留跳转录单页的链接（F01 关系图已同步）。
3. **FP 落点形态提示**：FP1-05、FP2-01、FP2-02、FP5-02 与 FP3 全系列录入均以**弹窗**承载；开发拆任务按弹窗工作量计，勿按整页计。
4. **跨模块联动**：租出台账「退回」改跳退租验收列表（就地弹窗录单），呼应租赁循环（REQ-03 ↔ REQ-11）。
5. **FP4-03（循环状态管理）落点核对**：在租资产跟踪页已有「循环状态」列 + 「循环状态流转」卡片（含报废需资产管理员审核说明），落点成立。
6. 需求疑点：未发现弹窗承载 FP 之外的功能，无需回填 P1-R01 第八节。

## 六、菜单最终结构（2026-09-01 版）

```
首页          → 项目看板（跨项目经营总览）
项目管理      → 项目档案（详情由行内「详情」进入）
基础数据      → 往来单位 / 包材档案 / 零部件档案 / 子母件BOM / 库位档案
仓储作业      → 采购入库 / 小组装 / 组合出库 / 退租验收 / 盘点管理 / 库存查询
租赁管理      → 租出台账 / 在租资产跟踪 / 缺损赔偿
订单协同      → 下单入口（客户侧）/ 订单审核（我方侧）/ 路凯下发 / 结算导出
财务协同      → 应收账单 / 开票登记 / 回款登记 / 水单核销 / 盈亏报表
系统管理      → 用户权限 / 操作日志 / 数据字典
```

> 排序规则：首页总览 → 分析（项目管理）→ 主数据（基础数据）→ 业务流（仓储→租赁→订单→财务，子项按 F02/F04/F03 单据流转序）→ 配置（系统管理）。
