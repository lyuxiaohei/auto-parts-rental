4. **外发 HTML（P1-R01*.html）是快照**，直接改会被下次转换覆盖。

6. **批量脚本教训（2026-09-04 L3/L4 改造实录）**：①侧边栏批量插入的跳过条件不能用"页面含某链接字符串"判断（会误跳含该跳转的业务页/漏跳 selected 页）——应以"页面是否已含新菜单行"精确判断；②生成函数返回格式化模板时漏写 `% 变量` 会静默产出字面 `%s`（必须抽查生成文件内容，DOM 计数通过≠文本正确）；③Playwright 断言跳转时 `pg.url` 中文被 percent-encode，需 `unquote()` 后再判断；`innerText` 受可见性影响，校验文本用 `textContent`。
